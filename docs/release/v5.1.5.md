# Vega 5.1.5

## Perfis, segurança e administração de servidores

- introduz perfis `desktop` e `server` no `vegad`, com descoberta de
  capacidades via D-Bus;
- restringe CLI e Web a pacotes nativos e adiciona alertas de atualização
  adequados a cada perfil;
- fortalece restauração de backups, acesso a logs, autenticação, sessões Web,
  TLS e unidades systemd;
- remove o catálogo chinês e mantém fallback explícito para inglês;
- adiciona testes integrados de D-Bus, empacotamento e pipeline de CI.
