# Vega 5.1.22

## Instalação NVIDIA falhava quando kmp e userspace desalinhavam no repo

- corrige a instalação do driver NVIDIA G06 falhar com um conflito do
  Zypper quando a NVIDIA publica `nvidia-userspace-meta-G06` numa versão
  para a qual `nvidia-open-driver-G06-signed-kmp-meta` ainda não tem build
  correspondente — o Vega pedia "a mais recente" de cada pacote na mesma
  transação e o solver não conseguia resolver, mesmo havendo uma versão
  mais antiga disponível nos dois;
- o Vega agora resolve a maior versão presente simultaneamente nos dois
  metapacotes no `repo-nvidia` e instala pinado nela, em vez de deixar cada
  um resolver para "latest" de forma independente;
- quando não existe nenhuma versão em comum entre os dois pacotes, o erro
  agora é claro ("repositório NVIDIA está temporariamente desalinhado...")
  em vez do dump bruto do solver do Zypper.
